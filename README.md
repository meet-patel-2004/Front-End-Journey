# Amazon Clone

An Amazon-inspired frontend demo storefront built with HTML, CSS, and vanilla JavaScript.

## Description

This is a frontend-only clone of the Amazon website, created as a coding journey project. It provides a simulated shopping experience with categories, search functionality, product listings, best sellers, and promotional deals — all styled to resemble the Amazon UI.

## Features

- **Category Browse** – Navigate through Electronics, Fashion, Home, and other departments
- **Search** – Filter products by category and search term
- **Product Grid** – Display best-selling items with images, descriptions, and pricing
- **Bestsellers** – Highlight top-rated products with star ratings
- **Deals Section** – Show promotional offers and discounted items
- **Responsive Design** – Works on desktop, tablet, and mobile devices
- **Modern UI** – Clean, dark-themed interface with Amazon-inspired branding

## Project Structure

```
AmazonClone/
├── index.html    # Main HTML structure and layout
├── style.css     # All styling and visual design
```

## How to Run

1. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari)
2. No build tools or dependencies are required — it's a static frontend project
3. The site is fully self-contained and runs directly in the browser

## Technologies

- **HTML5** – Semantic markup for the storefront
- **CSS3** – Modern styling with custom properties, responsive design, and animations
- **Vanilla JavaScript** – Client-side interactivity (search, filtering, cart simulation)
